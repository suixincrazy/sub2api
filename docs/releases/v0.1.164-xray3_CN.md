# Sub2API Xray v0.1.164-xray3 修复及更新

发布日期：2026-07-25

## 官方功能同步

- 同步官方 `v0.1.162` 至 `v0.1.164` 的功能与修复。
- 新增聚合分组，可按模型将请求路由至不同平台的子分组。
- 新增分组级 OpenAI 推理策略控制。
- 支持 Ollama Cloud 官方用量自动同步。
- 支持 Grok `/responses/compact`、工具缓存及相关兼容能力。
- Redis 支持 ACL 用户名配置。
- 新增客户端真实 IP、可信代理及自定义 IP 请求头设置。
- 异步生图对象存储改为后台配置并支持即时生效。
- 更新检查支持配置 GitHub Token。
- 支付宝移动端支付支持客户端深链唤起。

## 代理与订阅兼容

- 优化 Clash、Base64 订阅及常见节点链接的解析兼容性。
- 完善 VMess、VLESS、Trojan 的 WebSocket、gRPC、HTTPUpgrade、XHTTP 和 SplitHTTP 参数转换。
- 增加 Xray KCP/mKCP、流量伪装、Seed、上下行容量及缓冲参数支持。
- 完善 VMess 的 ALPN、TLS 及兼容参数处理。
- Shadowsocks 支持 `v2ray-plugin`、`simple-obfs` 和 Clash `obfs` 参数转换。
- SOCKS 节点统一使用 `socks5h`，由代理端完成域名解析。
- 对已被新版 Xray 移除的 HTTP/H2、QUIC 传输返回明确提示，避免生成无效配置。
- 订阅同步时保留嵌套的路径、Host、ServiceName、Reality、XHTTP 等节点参数。

## Xray 与 sing-box

- 修复账号绑定 sing-box 节点后出现 `unsupported proxy scheme "sing-box"`、显示正常但实际无法请求的问题。
- 账号请求现在会取得可供 HTTP 客户端使用的本地 SOCKS 地址。
- Xray 与 sing-box 运行实例支持空闲回收，默认空闲时间为 15 分钟。
- 修复连续执行代理测试后出现 `sing-box runtime per-user instance limit reached (16)` 的问题。
- 连接测试改用独立短期运行实例，并在成功、失败或异常时自动释放。
- 运行时无法启动时返回明确错误，不再错误显示为不支持的代理协议。
- 改进新版 Xray 的 TLS 证书固定及兼容处理。

## IP 管理与我的代理

- 新增和更新订阅节点后自动执行一次质量检测。
- 管理员“IP管理”和用户“我的代理”统一使用实际代理运行时进行连接测试。
- 基础连接正常但部分检测目标不可访问时标记为“警告”，不再直接判定代理完全失效。
- 增加质量检测引擎版本标识，旧版缓存结果不会覆盖新版检测状态。
- 优化代理延迟、质量状态及连接失败信息的保存和展示。

## 账号与代理权限

- 管理员在“账号管理”中可以选择和使用全部代理资源。
- 普通用户仍只能使用自己的代理或已公开代理。
- 数据库约束同步适配管理员全局代理权限，不影响用户资源隔离。
- 修复账号代理选择与实际运行时状态不一致的问题。

## 在线更新与 Docker

- 修复 Docker 非 root 用户执行在线更新时出现 `internal error` 的问题。
- 应用目录调整为运行用户可写，支持安全替换更新文件。
- GitHub Release 下载超时延长至 45 分钟。
- 更新与回滚请求超时延长至 50 分钟，改善网络较慢时的更新成功率。
- Docker 镜像增加 Xray 与 sing-box 空闲回收配置。

## 其他修复

- 修复 OpenAI OAuth 请求输入格式异常。
- 修复 OpenAI 流式请求异常断开后故障代理未及时隔离的问题。
- 修复 Grok 402、策略类 403 及配额状态处理。
- 优化网关 SSE、Responses、Codex 与 Anthropic 兼容。
- 修复优雅关停时部分用量和计费记录可能丢失的问题。
- 优化调度器、渠道监控、缓存计费和模型定价匹配。
- 修复 API Key 部分更新时可能清空 IP 白名单或黑名单的问题。
- 完善账号管理、运维监控及其他页面的移动端显示与滚动适配。
