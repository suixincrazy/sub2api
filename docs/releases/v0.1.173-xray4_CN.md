# Sub2API Xray v0.1.173-xray4 修复及更新

发布日期：2026-08-11

`v0.1.173-xray4` 是 `xray3` 的安全与兼容性修订版，包含发布后完成的修复及官方 `0.1.173` 同版本最新提交。旧 `v0.1.173-xray3` Tag 仅保留作历史记录，新部署和升级请使用 `xray4`。

## 本次修复

- 修复 API Key 鉴权查询与两级缓存未完整保留私有分组所有者的问题，避免外部用户在缓存命中后被错误放行；认证快照版本同步提升，旧快照会自动失效。
- 修复管理员通过余额或并发调整流程创建兑换记录时，使用历史未同步写入新历史表的问题；记录创建与历史写入现在位于同一事务内。
- 对齐账号与组合分组创建、更新所使用的原子仓储契约，完善相关回归测试。
- 将 Xray 运行时及安全测试中的关键类型断言改为显式校验，避免异常数据被静默接受。
- 同步官方 `v0.1.173` 发布后的同版本修复提交，同时保留 Xray 的代理运行时、用户资源隔离、订阅分发及独立仓库配置。

## 发布与验证

- GitHub CI 的前端检查、Shell 检查、Go lint、后端单元测试和集成测试已全部通过。
- 本次发布重新生成五个平台安装包、校验文件及 GHCR amd64/arm64 多架构镜像。
- `latest`、`0.1`、`0` 标签将随本次发布重新指向 `0.1.173-xray4`。

## 升级说明

- Docker：`docker pull ghcr.io/smooonn/sub2api-xray:0.1.173-xray4`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/SMOOONN/sub2api-xray/main/deploy/install.sh | sudo bash`
- 升级前请继续保留数据库与应用数据备份；应用启动后会自动执行所需迁移。

> 注：本文档为历史发行说明。上面命令中的仓库与镜像地址属于当时使用的账号，现已不可用。
> 当前仓库为 <https://github.com/smmooooonn/sub2api-xray>，当前镜像为 `ghcr.io/smmooooonn/sub2api-xray`。
