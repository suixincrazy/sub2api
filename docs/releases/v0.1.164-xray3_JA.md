# Sub2API Xray v0.1.164-xray3 修正および更新

リリース日：2026-07-25

## 上流機能の同期

- 上流 `v0.1.162` から `v0.1.164` までの機能と修正を同期しました。
- モデルごとに異なるプラットフォームの子グループへ転送できる複合グループを追加しました。
- グループ単位の OpenAI 推論ポリシー制御を追加しました。
- Ollama Cloud 公式使用量の自動同期に対応しました。
- Grok `/responses/compact`、ツールキャッシュ、および関連する互換機能に対応しました。
- Redis ACL ユーザー名設定に対応しました。
- クライアント IP モード、信頼済みプロキシ、カスタム IP ヘッダー設定を追加しました。
- 非同期画像生成のオブジェクトストレージ設定を管理画面へ移し、保存後すぐに反映されるようにしました。
- 更新確認で GitHub Token を設定できるようにしました。
- Alipay モバイルアプリのディープリンク起動に対応しました。

## プロキシと購読の互換性

- Clash、Base64 購読、一般的なノードリンクの解析互換性を改善しました。
- VMess、VLESS、Trojan の WebSocket、gRPC、HTTPUpgrade、XHTTP、SplitHTTP パラメーター変換を改善しました。
- Xray KCP/mKCP、トラフィック偽装、Seed、上下方向容量、バッファーパラメーターに対応しました。
- VMess の ALPN、TLS、および互換パラメーター処理を改善しました。
- Shadowsocks の `v2ray-plugin`、`simple-obfs`、Clash `obfs` 変換に対応しました。
- SOCKS ノードを `socks5h` に統一し、DNS 解決をプロキシ側で行うようにしました。
- 現行 Xray で削除された HTTP/H2、QUIC 転送方式には明確なエラーを返し、無効な設定を生成しないようにしました。
- 購読同期時にネストされた Path、Host、ServiceName、Reality、XHTTP パラメーターを保持します。

## Xray と sing-box

- sing-box ノードを割り当てたアカウントが正常表示でも `unsupported proxy scheme "sing-box"` で失敗する問題を修正しました。
- アカウント通信で HTTP クライアントが利用できるローカル SOCKS URL を取得するようにしました。
- Xray と sing-box のアイドルインスタンス回収を追加し、既定のアイドル時間を 15 分にしました。
- プロキシ接続テストを繰り返すと `sing-box runtime per-user instance limit reached (16)` が発生する問題を修正しました。
- 接続テストは独立した短期ランタイムを使用し、成功、失敗、例外のいずれでも自動的に解放します。
- ランタイムを起動できない場合、未対応プロトコルとして誤表示せず明確なエラーを返します。
- 現行 Xray 向けの TLS 証明書固定と互換処理を改善しました。

## IP 管理とマイプロキシ

- 購読ノードの新規作成または更新後に品質検査を一度自動実行します。
- 管理者の IP 管理とユーザーのマイプロキシで、実際のプロキシランタイムを使用して接続をテストします。
- 基本接続が成功し、一部の検査先だけが利用できない場合は、完全な失敗ではなく警告として表示します。
- 品質検査エンジンのバージョン識別子を追加し、旧キャッシュが新しい結果を上書きしないようにしました。
- プロキシ遅延、品質状態、接続失敗情報の保存と表示を改善しました。

## アカウントとプロキシ権限

- 管理者はアカウント管理からすべてのプロキシリソースを選択して使用できます。
- 一般ユーザーは引き続き自分のプロキシまたは公開プロキシだけを使用できます。
- ユーザーリソース分離を維持したまま、管理者の全体プロキシ権限にデータベース制約を対応させました。
- アカウントで選択したプロキシと実際のランタイム状態が一致しない問題を修正しました。

## オンライン更新と Docker

- Docker の非 root ユーザーがオンライン更新を実行した際に `internal error` となる問題を修正しました。
- 実行ユーザーがアプリケーションディレクトリへ書き込めるようにし、更新バイナリを安全に置換できるようにしました。
- GitHub Release のダウンロードタイムアウトを 45 分へ延長しました。
- 低速ネットワーク向けに更新とロールバックのリクエストタイムアウトを 50 分へ延長しました。
- Docker イメージへ Xray と sing-box のアイドル回収設定を追加しました。

## その他の修正

- OpenAI OAuth リクエストの入力形式を修正しました。
- OpenAI ストリーミング切断後に障害プロキシの隔離が遅れる問題を修正しました。
- Grok の 402、ポリシー関連 403、クォータ状態の処理を改善しました。
- SSE、Responses、Codex、Anthropic ゲートウェイ互換性を改善しました。
- グレースフルシャットダウン時に一部の使用量・請求記録が失われる可能性を修正しました。
- スケジューラー、チャネル監視、キャッシュ請求、モデル価格照合を改善しました。
- API Key の部分更新で IP 許可リストまたは拒否リストが消去される可能性を修正しました。
- アカウント管理、運用監視、その他の画面でモバイル表示とスクロールを改善しました。
