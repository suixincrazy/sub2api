# Sub2API Xray v0.1.173-xray3 修复及更新

发布日期：2026-08-11

## 官方功能同步

- 同步官方 `v0.1.169` 至 `v0.1.173` 的功能、性能优化与安全修复。
- 收紧上游 URL 路径片段校验，修复可控路径片段参与上游请求拼接的安全风险。
- Docker 默认启用 `no-new-privileges`，降低应用进程提权风险。
- 修复 OAuth 登录补全流程的账号接管风险，并改进访问令牌刷新并发处理。
- 新增腾讯天御和阿里云验证码 2.0，并将验证码服务商统一为互斥选择。
- 新增 Passkey 登录支持及部署配置说明。
- 新增上游响应模型审计，可识别上游替换或降级模型的情况。
- Antigravity 支持 Gemini 3.6 Flash 系列模型。

### 代理与订阅

- 修复同步官方版本后，IP 管理中 Xray 分享链接、机场订阅、Sing-box / Clash 配置等添加方式丢失的问题。
- IP 管理的添加方式恢复为下拉选择，并按照“名称、添加方式、协议”的顺序重新整理表单。
- 管理员支持标准代理、Xray 分享链接、机场订阅及 Sing-box / Clash 配置导入。
- Sing-box / Clash 配置支持直接粘贴或选择本地 `.json`、`.yaml`、`.yml`、`.txt`、`.conf` 文件。
- 完善 HTTP、HTTPS、SOCKS、VMess、VLESS、Trojan、Shadowsocks、Hysteria、TUIC、AnyTLS、Naive、WireGuard 等节点格式识别。
- 新增系统订阅源管理，支持创建、编辑、定时同步、立即同步、公开设置、删除及分页管理。
- 导入代理或同步订阅后自动执行一次质量检测。
- 修复重复同步时已更新代理数量显示为 0 的问题。
- 修复批量连接测试和质量检测忽略资源所有者筛选的问题。
- 修复系统订阅源超过 100 条后无法继续管理的问题。
- 完善代理导入参数校验和敏感错误信息处理。
- 移除代理添加界面的推广入口。

### 账号与界面

- 修复管理员创建或编辑账号时系统分组不显示的问题。
- 修复管理员账号配置流程中系统代理的选择与校验问题。
- 优化“我的账号”“我的代理”及管理端添加弹窗在窄屏和移动端的布局与横向滚动。
- 保留 Xray 代理运行时、账号代理绑定、用户私有资源、公开代理和用户权限隔离。
- 保持“我的账号”“我的代理”原有操作流程和用户权限边界。

## Docker 与升级提示

- 保留 Xray 与 sing-box 运行时、独立测试实例、空闲回收和异常清理能力。
- 修复非 root 用户执行在线更新时的 `internal error`，并改进更新、回滚超时和可写目录处理。
- 本版本包含官方数据库迁移；升级前应保留数据库和应用数据备份，启动后由应用自动执行迁移。
- 官方迁移会清理非 Grok 分组残留的视频定价配置；Grok 跨厂商模型映射默认关闭，旧行为需手动开启。

## 兼容范围

- 官方网关、账号、计费、订阅、支付、验证码、备份和运维能力继续保留。
- Xray 项目的代理解析、运行时、资源隔离、账号代理和管理界面能力继续保留。
- 本项目按此前要求移除赞助推广图片及代理添加页推广组件，仅影响推广展示，不影响 API、代理、订阅、账号或数据库功能。
