# Sub2API Xray v0.1.184-xray4 更新说明

发布日期：2026-09-02

同步官方 `v0.1.184` 及其对应的最新 `main` 提交 `200602b41`（位于官方 `v0.1.184` Tag 之后 4 个提交）。

## 官方功能同步

- 新增「按用户限制可绑定的公开分组」开关：开启后该用户只能绑定白名单内的公开分组，默认对现有用户不生效。
- 新增智谱 GLM Coding Plan 团队用量查询。
- 新增 Ollama 用量统计对国内平台的支持。
- 新增注册时使用优惠码，覆盖 OAuth 注册链路。
- 新增透传 HTTP 桥接，并将透传 WebSocket 链路独立隔离。
- 用量日志新增原生远端压缩（compaction v2）标记，以及「客户端请求的推理强度」字段，后者记录分组策略改写与模型族映射之前的原始值。
- 新增 Fable 模型适配：调度阈值只作用于 Fable 模型，并修正 Fable OAuth 场景下系统提示被拒的问题。
- 计价修正：DeepSeek 分时价格对齐官方，带后缀的模型名不再被官方兜底价覆盖，Codex OAuth 服务层级计费更正，充值汇率按所选币种展示。
- OpenAI 与 Codex 链路修正：TTFT 设置界面、重新授权时的 refresh token、reasoning 重放、原始流截断、`/v1/responses` 透传的预输出保活、Claude Code 会话粘性路由、图片能力冷却不再依赖文本启发式、自定义供应商的图片输入能力不再丢失、API Key 模式内联鉴权。
- Grok、Anthropic、Antigravity 兼容修正：Grok 视觉工具输出与 grok-4.6 xhigh、旁路调用的 prompt cache key、Anthropic 工具参数与 reasoning 回传、Antigravity 混合内置工具。
- 管理端与前端修正：用量统计卡片在窄屏不再横向溢出、统一用量窗口样式、分组创建与更新会显示接口错误信息、SMTP TLS 模式在测试端点保留、批量编辑可以关闭 Codex 指纹收敛、账号到期时间的时区、上游倍率探测不再导致账号列表整页刷新、监控按分组作用域生效、配额抓取不再重复查询上游。
- 订阅与配额修正：周／月窗口展示的重置时间与实际推进锚点对齐，重置卡调度器的速率限制与配额上限保留。
- 更新检查同步官方对版本号比较的修正（比较时忽略连字符后缀）；Xray 自身的 `-xray` 版本识别保持不变。
- 以及若干上游协议兼容与稳定性修复。

## 升级方式

- Docker：`docker pull ghcr.io/smmooooonn/sub2api-xray:0.1.184-xray4`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/smmooooonn/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含新的数据库迁移。升级前请保留 PostgreSQL、Redis 和应用数据备份，应用启动后会自动执行迁移。
