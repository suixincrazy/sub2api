# Sub2API Xray v0.1.176-xray4 更新说明

发布日期：2026-08-15

`v0.1.176-xray4` 同步官方 `v0.1.176` 及其对应的最新 `main` 提交，并继续保留 Xray 的用户私有资源池、订阅分发、代理绑定、内置 Xray / sing-box 运行时和独立更新链路。

## 官方功能同步

- 分组新增逐模型定价和长上下文阶梯定价开关，相关管理界面、计费解析、缓存失效与回归测试同步更新。
- Grok 新增 `grok-4.6`、订阅档位识别、原生 `/x_search`、搜索计费及音频计费修正，改善配额刷新和异常退避行为。
- 新增分组日用量汇总、时区迁移和管理端分组用量查询，降低长期统计查询开销。
- 改进 OpenAI Responses / Chat Completions 的压缩路由、可见输出 TTFT、设备指纹、请求探测及 WebSocket 转发兼容性。
- 定时备份加入多实例 leader 锁；完善安全审计范围、HTML 403 识别、渠道缓存与定价冲突检测。
- 同步前端账号用量刷新、Grok 档位展示、分组列设置、运营监控格式化以及依赖安全更新。

## Xray 兼容范围

- 保留管理员与普通用户之间的资源所有权隔离，以及用户自有账号、代理、兑换码和分组访问边界。
- 保留 Xray 分享链接、机场订阅、Sing-box / Clash 配置导入和运行时生命周期管理。
- 保留独立仓库、独立 GHCR 镜像和测试实例在线更新流程；项目文档继续移除上游赞助推广区块。

## 升级说明

- Docker：`docker pull ghcr.io/smooonn/sub2api-xray:0.1.176-xray4`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/SMOOONN/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含新的数据库迁移。升级前请保留数据库及应用数据备份，应用启动后会自动执行迁移。

> 注：本文档为历史发行说明。上面命令中的仓库与镜像地址属于当时使用的账号，现已不可用。
> 当前仓库为 <https://github.com/smmooooonn/sub2api-xray>，当前镜像为 `ghcr.io/smmooooonn/sub2api-xray`。
