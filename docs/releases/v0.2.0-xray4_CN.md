# Sub2API Xray v0.2.0-xray4 更新说明

发布日期：2026-09-03

同步官方 `v0.2.0` 及其对应的最新 `main` 提交 `5097b3145`（位于官方 `v0.2.0` Tag 之后 1 个提交）。

## 官方功能同步

- 新增 Claude Fable 5.1 支持。
- 新增分组「强制 OpenAI Fast」开关：开启后该分组的 OpenAI 链路统一走 Fast，复制分组与分组生命周期均保留该设置。
- 新增分组「Fast 免费」开关：命中的 Fast 请求按标准价计费，不额外加价。
- 分组推理强度上限新增「超出上限时拒绝或降级」选择，默认降级。
- 分组的 OpenAI 推理强度自定义映射可按模型精确名、前缀或后缀限定，先映射再应用上限。
- 新增 Kimi 透传原生 OpenAI Responses API。
- 计价目录改造：长上下文阶梯计价改为价格目录数据驱动，新增 `override_file` 价格覆盖补丁，新增渠道 cache 1 小时写入价，并修正 Gemini Pro 缓存写入价与目录字段契约校验。
- 账号用量统计的成本改为复用与用户计费同一条计价管线，两处口径一致（图片输出、长上下文阶梯、服务层级都自动跟随）。
- Codex 修正：生成的模型目录会声明 Fast 服务层级；持续处于禁用状态的目录账号不再参与调度。
- OpenAI 链路修正：API Key 模式保留对话缓存标识、不再为 API Key 合成 instructions、定时自动化与委派场景允许缺少 call id 的引导请求、WebSocket 在终止事件前不再提前关闭、空闲连接池回收陈旧连接、ctx_pool WebSocket 入口在下发前改写上游容量降载错误码。
- 网关修正：单模型冷却不再把 404 model_not_found 变成 429；请求带 `fallbacks` 字段但最终 beta 头不含 server-side-fallback 时，转发前会剥掉该字段（避免被 Anthropic 上游按「不允许的额外字段」拒绝），Bedrock 通道无条件剥离；调度快照保留 OpenAI 透传标记。
- 数据库瞬时错误重试放宽到 8 次并覆盖启动阶段，宿主机或 Docker 重启后应用不再因 PostgreSQL 仍在恢复而启动失败；Compose 示例同步放宽了应用与 PostgreSQL 的健康检查宽限期。
- 前端修正：分组模型定价弹窗布局优化。
- 以及若干上游协议兼容与稳定性修复。

## 升级方式

- Docker：`docker pull ghcr.io/smmooooonn/sub2api-xray:0.2.0-xray4`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/smmooooonn/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含新的数据库迁移。升级前请保留 PostgreSQL、Redis 和应用数据备份，应用启动后会自动执行迁移。
