# Sub2API Xray v0.1.177-xray4 更新说明

发布日期：2026-08-17

同步官方 `v0.1.177` 及其对应的最新 `main` 提交，并继续保留 Xray 的用户私有资源池、订阅分发、代理绑定、内置 Xray / sing-box 运行时和独立更新链路。

## 本次更新

- Codex 请求统一补齐会话级 `remote_compaction_v2` beta 标识，覆盖常规 `/responses`、WebSocket 握手和压缩请求，与官方客户端保持一致。
- 账号“压缩测试”改用原生 remote compaction v2 探测；v2 请求继续使用 `/responses`，避免旧压缩接口下线后误报失败。
- 完整回传 `x-codex-turn-state` 并校验状态来源，避免故障切换时在不同账号之间复用回合状态。
- Codex OAuth 指纹收敛改为显式启用；未配置账号默认透传客户端标识，透传请求也会遵循账号已选配置。
- 更新账号创建、编辑和批量编辑界面的指纹收敛选项及中英文提示。

## 升级方式

- Docker：`docker pull ghcr.io/smooonn/sub2api-xray:0.1.177-xray4`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/SMOOONN/sub2api-xray/main/deploy/install.sh | sudo bash`
- 升级前仍建议保留 PostgreSQL、Redis 和应用数据备份。

> 注：本文档为历史发行说明。上面命令中的仓库与镜像地址属于当时使用的账号，现已不可用。
> 当前仓库为 <https://github.com/smmooooonn/sub2api-xray>，当前镜像为 `ghcr.io/smmooooonn/sub2api-xray`。
