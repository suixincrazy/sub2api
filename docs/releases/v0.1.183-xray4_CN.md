# Sub2API Xray v0.1.183-xray4 更新说明

发布日期：2026-08-29

同步官方 `v0.1.183` 及其对应的最新 `main` 提交 `efb46db0a`（位于官方 `v0.1.183` Tag 之后 21 个提交），并继续保留 Xray 的用户私有资源池、订阅分发、代理绑定、内置 Xray / sing-box 运行时和独立更新链路。

## 官方功能同步

- 升级到官方 Go 1.27.0 工具链。
- 新增 OAuth 出站传输插件系统，并在管理端提供插件管理界面。
- 新增渠道分时段计价与服务层级倍率，模型广场同步展示分时口径。
- 新增 OpenAI Fast 服务层级，覆盖 Responses、Chat Completions 和 WebSocket 链路。
- 新增 OpenAI 重置卡按用量阈值自动使用。
- 新增账号自适应 API 协议路由、可配置 429 冷却与重试策略、可配置代理探测目标和网关模型列表读取上限。
- 完善 Codex 路由模型目录，运维监控错误详情支持列表展示并保留筛选状态。
- 同步 OpenAI Responses、WebSocket、Codex 工具调用与会话亲和修复。
- 同步 Grok、Kimi、Antigravity、Ollama 和 Composite 分组的兼容更新，以及渠道监控聚合修复。
- 对齐 Docker 网关默认配置。

## 仓库与镜像地址变更

本版本起，本项目的仓库、容器镜像和更新检查全部迁移到新的发布账号：

- 仓库：<https://github.com/smmooooonn/sub2api-xray>
- 镜像：`ghcr.io/smmooooonn/sub2api-xray`

旧账号下的仓库与镜像已不再可用，旧版本实例的“检查更新”会因此失败。请按下面的命令手动升级一次；升级到本版本后，更新检查会自动指向新仓库。

## 升级方式

- Docker：`docker pull ghcr.io/smmooooonn/sub2api-xray:0.1.183-xray4`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/smmooooonn/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含新的数据库迁移。升级前请保留 PostgreSQL、Redis 和应用数据备份，应用启动后会自动执行迁移。
