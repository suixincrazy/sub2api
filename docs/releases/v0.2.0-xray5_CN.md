# Sub2API Xray v0.2.0-xray5 更新说明

发布日期：2026-09-03

本版本与上一版基于同一官方基线 `v0.2.0`，未做新的官方同步；改动全部来自 Xray 自身。

## 新增功能：订阅源管理

- 一键同步全部订阅源：用户端「我的代理」与管理端「代理管理」都新增一键同步，按源返回成功、部分成功、失败、已跳过的汇总；已暂停的源不会被触发，单次请求时间用尽时剩余的源转交后台调度器继续补齐。
- 每个订阅源显示节点数，并可按源筛选：列表与弹窗都会实时统计该源当前的节点数与可用节点数，点击即可只看该源的节点；管理端还可与「归属范围」组合筛选。
- 启用／暂停开关与下次更新时间：每个源都能单独暂停自动同步，暂停后不再排期、下次更新时间清空，恢复后按刷新间隔重新排期。
- 机场剩余流量与到期时间：同步时会读取订阅提供方在响应中回报的配额信息并显示已用流量、总量与到期时间；提供方未回报时该处显示 `-`，不影响节点同步。

## 修复与加固

- 修复「我的代理」与管理端「代理管理」的工具栏按钮在中等宽度窗口下被挤成窄窄一列、按钮文字被断开换行的问题；按钮组改为整排换行并保持右对齐，窗口足够宽时仍与筛选条同排显示。
- 修复顶栏用户菜单在用户名较长且页面出现纵向滚动条时，整页出现 1 像素横向溢出的问题；用户名过长时改为省略号显示。

## 升级方式

- Docker：`docker pull ghcr.io/smmooooonn/sub2api-xray:0.2.0-xray5`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/smmooooonn/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含新的数据库迁移。升级前请保留 PostgreSQL、Redis 和应用数据备份，应用启动后会自动执行迁移。
