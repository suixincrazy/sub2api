# Sub2API Xray v0.2.4-xray5 更新说明

发布日期：2026-09-13

本版本同步官方 v0.2.4，Xray 自身能力全部保留。

## 官方新功能

- 用户分组模型白名单改名为模型允许清单，并从此同时约束列表展示与请求准入：启用白名单且列表为空时，列表正常返回空数组，但发往该白名单覆盖的模型会返回 400；禁用白名单时列表与准入都不限制。迁移执行后既有白名单内容完全保留。
- 渠道监控新增 MiniMax 提供方支持。
- 优化 GitHub OAuth 回调逻辑：pending 状态下的 exchange 端点改为只读守卫，不再产生有副作用的请求。
- 若干上游协议兼容与稳定性修复。

## 升级方式

- Docker：`docker pull ghcr.io/smmooooonn/sub2api-xray:0.2.4-xray5`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/smmooooonn/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含新的数据库迁移。升级前请保留 PostgreSQL、Redis 和应用数据备份，应用启动后会自动执行迁移。
- 更新完成后请先重启服务，再执行回退操作。
